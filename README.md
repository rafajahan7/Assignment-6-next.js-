This project name is"Fitlog".Fitlog is basically an workout management system designed for gym lovers and bodybuilders.Anyone can easily keep track of their workouts in this project and also they can save workouts to try for later.Technologies that are used in this project are-
1.next.js
2.react
3.react-toastify
4.daisy-ui
5.tailwind-css
5 key features of this project are-
-to be able to watch workouts
-to save workouts for later
-to view details of workout
-to add workouts to today's plan
-to track and manage selected workouts
